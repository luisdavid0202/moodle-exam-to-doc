# Frontend — Moodle Exam to Doc

Web interface built with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **shadcn/ui** components.

Lets you upload a Moodle quiz `.html` file and its `.zip` image bundle, then downloads the `.docx` document generated by the backend.

## Requirements

- Node.js 18+

## Setup

```bash
npm install
```

## Development

```bash
npm run dev        # dev server at http://localhost:3000
```

## Production

```bash
npm run build
npm run start
```

## Other commands

```bash
npm run lint       # ESLint
npm run format     # Prettier (TS/TSX)
npm run typecheck  # type-check without emitting
```

## Adding shadcn/ui components

```bash
npx shadcn add <component-name>
```

Components are placed in `components/ui/`.

## Backend URL

The backend is pointed to directly in `app/page.tsx`:

```ts
const API_URL = "http://localhost:8000"
```

Update this constant if the backend runs on a different host or port.
